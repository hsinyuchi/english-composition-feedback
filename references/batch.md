# 全班輸出與省力流程

## 資料主檔

以結構化記錄作為唯一來源，產生個人 PDF、Excel 與錯誤講義，避免在多個成品手動重填。每生有穩定 student_id、班級、座號、姓名、身份核對狀態、原始檔及頁碼、逐字稿、段落與句號、辨識疑義、字數核算、分項分數、扣分及總分、双語評語、逐句修改、三項任務、兩種雙語範文、輸出檔名與版本。

批次前先核對掃描頁與名單，不假定一頁必然一位學生。跨頁作文先歸戶；同名用班級與座號區別；無法確認者進待核對清單，不強配身份。單篇樣本確認後才擴至全班。

## 三種交付

1. 每生一份完整 PDF：`班級_座號_姓名_題目_精修_vN.pdf`；姓名未知用「待核對」。只供教師指定方式分發。
2. 全班前兩頁合併 PDF：班級、數字座號排序，每人正好兩頁，雙面印不混學生。明確列出完成／缺漏／待核對人數。樣本版標明只含一人。
3. 教師 Excel：凍結標題、篩選、數字格式、合理欄寬與換行；加總及統計以公式產生並核對。不要將未填資料記成零分。

Excel 建議工作表：

| 工作表 | 欄位 |
|---|---|
| 成績總表 | student_id、班級、座號、姓名、身份狀態、四項原稿分數、扣分、總分、教師實算字數、各段字數、學生自填字數、差異、評分來源、PDF檔名、版本 |
| 教師評語 | 英中短評、英中完整評語、優點、最優先改善項目 |
| 修訂追蹤 | 三項個別任務、應交證據、完成狀態、學生修訂稿位置、複評分數、日期 |
| 錯誤紀錄 | student_id、句號、類別、原文、修正、理由、是否待核對 |
| 學習反思 | 自評題目、前後自評、是否回溯、修訂證據、下一篇目標；全部學生答案初始留白 |
| 班級摘要 | 已批人数、待核對數、各項平均、錯誤出現次數、各類錯誤涉及的不重複學生數 |

「錯誤次數」與「犯此錯誤的學生數」分開統計。未核實文字不計為確認錯誤。學生人數依 student_id 去重，不能用錯誤筆數代替。平均排除空白、保留真正的零分。

## 合併工具名單

`manifest.json` 是陣列，各 PDF 路徑相對於 manifest 所在目錄，或使用絕對路徑：

```json
[
  {"student_id":"sample-01", "class":"301", "seat":1, "pdf":"individual/sample-01.pdf"},
  {"student_id":"sample-02", "class":"301", "seat":2, "pdf":"individual/sample-02.pdf"}
]
```

工具拒絕重複 student_id、同班重複座號、不足兩頁、空名單及既有輸出。逐生擷取前兩頁後再驗證頁數；保留名單用於追溯。

## 匿名共通錯誤講義

全班批完後才根據實際高頻錯誤製作，挑 3–5 項高影響問題。移除姓名、座號、可識別細節及原稿影像。優先以改寫的匿名例句呈現「找錯→修正→解釋→遷移練習」，答案另頁供教師使用。統計註明樣本數，不凭單篇推論全班。

## 交付前

比對分項加總、扣分、PDF與Excel分數、字數、姓名及檔名；合併頁碼必須等於學生數乘二，且每位前兩頁與原 PDF 一致。用試算表引擎測試至少一筆分數變動會更新總分，以及同一學生多筆錯誤不重複算人數。保存原稿及舊版本，不自動上傳、刪除或停止分享任何學生檔案。
